
# Com funciona la nostra web?

La nostra pàgina està pensada perquè qualsevol persona pugui demanar una cita de manera fàcil.

## Passos per reservar

1. **Consultar els serveis:** el client pot veure els serveis disponibles.
2. **Omplir el formulari:** introdueix les seves dades personals i de contacte.
3. **Escollir una data:** selecciona el dia i l'hora de la cita.
4. **Explicar el problema:** pot indicar què li passa al vehicle.
5. **Enviar la reserva:** les dades s'envien al sistema del taller.

D'aquesta manera, el client pot demanar una cita sense haver de fer una trucada telefònica.
