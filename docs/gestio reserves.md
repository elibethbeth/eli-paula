
# Gestió de reserves

La gestió de reserves permet al personal del taller consultar i organitzar les cites dels clients.

## Informació de les reserves

| Dada | Descripció |
| --- | --- |
| Client | Nom i cognoms |
| Telèfon | Contacte del client |
| Servei | Reparació necessària |
| Data | Dia de la cita |
| Hora | Hora seleccionada |
| Vehicle | Informació del cotxe |

Aquest sistema facilita la consulta de les dades i ajuda a mantenir les reserves més ben organitzades.
