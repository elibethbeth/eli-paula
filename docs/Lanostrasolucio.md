
# La nostra solució

Per solucionar els problemes que té actualment Vázquez Taller, hem creat una pàgina web que permet gestionar les reserves d'una manera més senzilla, ràpida i organitzada.

Amb aquesta web, els clients poden consultar els serveis del taller i demanar una cita sense haver de trucar o desplaçar-se fins al negoci.

El personal també pot consultar i gestionar les reserves, facilitant així la feina del dia a dia.

**El nostre objectiu és substituir el sistema de paper i Excel per una eina digital més pràctica i accessible.**
