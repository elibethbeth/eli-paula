
# Els nostres objectius

Amb aquest projecte volem millorar l'organització de Vázquez Taller i facilitar la comunicació amb els clients.

Els nostres principals objectius són:

- Facilitar la reserva de cites.
- Evitar reserves duplicades.
- Organitzar millor els horaris.
- Tenir les dades dels clients més ben organitzades.
- Facilitar la feina dels treballadors.
- Controlar les reserves i l'espai disponible.
- Crear una web senzilla i fàcil d'utilitzar.

## Què volem aconseguir?

Volem que tant els clients com els treballadors puguin estalviar temps i gestionar les cites d'una manera més còmoda.
