
# Taller IA – Assistent virtual

La nostra pàgina web incorpora un assistent virtual anomenat **Taller IA**.

Aquest assistent està pensat per ajudar els clients a resoldre dubtes relacionats amb els vehicles i els serveis del taller.

## Què pot fer?

- Respondre preguntes dels clients.
- Donar informació sobre els serveis.
- Oferir una primera orientació sobre possibles problemes del vehicle.
- Ajudar els usuaris abans de demanar una cita.

**Important:** l'assistent és una eina d'ajuda i no substitueix la revisió d'un mecànic professional.
