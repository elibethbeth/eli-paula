
# Tecnologies utilitzades

Per desenvolupar la nostra pàgina web hem utilitzat diferents tecnologies i eines informàtiques.

| Tecnologia | Utilitat |
| --- | --- |
| HTML | Crear l'estructura de la web |
| CSS | Dissenyar i donar estil a la pàgina |
| JavaScript | Afegir funcionalitats i interacció |
| Docker | Executar els serveis mitjançant contenidors |
| Nginx | Servir la pàgina web |

Aquestes eines ens han permès desenvolupar una pàgina adaptada a les necessitats de Vázquez Taller.
